📌 Overview

Emergency SOS is an Android-based safety application designed to send instant emergency alerts with location details to saved contacts.

It helps users quickly notify others in critical situations using a simple one-tap SOS system.

---

✨ Features

- 🚨 One-Tap SOS Alert
- 📍 Real-Time GPS Location Sharing
- 📩 Emergency SMS Sending
- 🔊 Optional Audio Recording
- 🔔 Notification Alerts
- 📱 Clean & Cinematic UI
- 🔐 Android 13+ Permission Support

- File → Open → Select project folder

Run the app

- Connect device/emulator
- Click Run ▶

---

🧠 How It Works

1. User taps SOS button
2. App fetches live location
3. Sends SMS with location link
4. Triggers alert system
